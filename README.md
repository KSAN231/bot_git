# Telegram Bot for Order Management

Telegram-бот на Python для автоматизации приёма и обработки заказов оптового склада.

## О проекте

Проект представляет собой Telegram-бота, который позволяет клиентам оформлять заказы, получать актуальные прайс-листы и сообщать о проблемах. Для администратора предусмотрены инструменты управления заказами и клиентской базой.

## Основные возможности

- Регистрация клиентов и сохранение их данных.
- Создание, редактирование и удаление заказов.
- Обработка текстовых заказов и файлов.
- Получение актуального прайс-листа.
- Изменение статусов заказов и отметка оплаты.
- Просмотр информации о клиентах и их заказах.
- Экспорт клиентской базы в Excel.
- Рассылка объявлений и отправка сообщений клиентам.
- Приём сообщений об ошибках.
- Создание резервных копий базы данных.

## Технологии

- **Python** — основная логика приложения.
- **pyTelegramBotAPI** — взаимодействие с Telegram Bot API.
- **SQLite** — хранение данных пользователей и заказов.
- **SQL** — выполнение операций с базой данных.
- **pandas** — экспорт данных в Excel.
- **python-dotenv** — загрузка конфигурации из переменных окружения.
- **logging** — ведение логов приложения.

## Структура репозитория

- `main.py` — обработчики команд Telegram, бизнес-логика и взаимодействие с пользователями.
- `db.py` — работа с SQLite, хранение и обработка данных пользователей и заказов.

## Архитектура

Логика Telegram-бота отделена от слоя работы с базой данных. Основные операции с пользователями и заказами вынесены в класс `Database`, что упрощает организацию кода и дальнейшее развитие проекта.

## Безопасность и конфигурация

Конфигурационные файлы, токены Telegram-бота и реальные данные пользователей не входят в публичный репозиторий.

Для полноценного запуска необходимы дополнительные вспомогательные модули и конфигурация, которые не включены в эту демонстрационную версию.

## Цель проекта

Практическое применение Python для разработки прикладного backend-приложения: работы с Telegram API, базой данных SQLite, обработкой файлов и автоматизацией бизнес-процессов.
